# Worker Management Attendance Frontend

Frontend for a worker attendance and geofencing system using Razor Views, Bootstrap RTL, and JavaScript.

The source expects an ASP.NET Core backend with Supabase PostgreSQL.

## Source
- `Views/` — Razor Views
- `wwwroot/` — CSS and JavaScript
- `docs/` — static GitHub Pages preview

## Important
The GitHub Pages version is a frontend preview only. Real check-in/check-out, geofencing, admin authentication, and Supabase access require the ASP.NET Core backend to be hosted separately.
